# Resume - Use this command only when the user explicitly asks to resume or recover work.

## Workflow

1. Read:
   - `git branch --show-current`
   - `git status --short`
   - `git diff --stat`
   - `git log --oneline --decorate -n 10`
2. If relevant to the current branch, skim matching files in `docs/superpowers/plans/` or `docs/superpowers/specs/`.
3. Summarize:
   - last completed work
   - work in progress
   - likely next steps
   - blockers or open decisions

## Rules

- Keep the summary short and action-oriented.
- Ask at most one clarifying question if multiple threads are active.
- Do not read broad unrelated repo context unless the current branch state is insufficient.
